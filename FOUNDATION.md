# Foundation

This repository is the multi-tenant specialization of `softwarepk/laravel-cpanel-starter`.

Keep the base starter's Laravel/Livewire/Flux/UI/tooling/deployment conventions, while preserving the additional invariants documented in `docs/TENANCY-ARCHITECTURE.md`.

Use the single-tenant starter when one organization owns the application. Use this starter when one deployment must serve multiple independent organizations with database-per-tenant isolation.
