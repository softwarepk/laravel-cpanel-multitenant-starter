# Tailwind CSS Development

Use Tailwind 4 with the existing CSS/UI primitives. Keep tenant and central administration screens restrained, accessible, responsive, and consistent. Prefer established spacing/type/action hierarchy over one-off decorative styling.

For reusable application presentation patterns, prefer `x-ui.*` components rather than repeating long utility strings across screens.
