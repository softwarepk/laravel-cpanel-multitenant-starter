# Livewire Development

Keep Livewire components thin and server-driven. Reuse Flux and `x-ui.*` patterns, validate server-side, and move substantial workflows into Actions/Services.

Tenant Livewire requests must retain the correct hostname and tenant context. Test any route/middleware/custom-domain change that could affect Livewire requests across tenant boundaries.
